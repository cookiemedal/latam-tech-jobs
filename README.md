# Empleos Tech Remotos para LATAM

Vacantes tecnológicas remotas que aceptan candidatos residentes en Latinoamérica y declaran contratación independiente, freelance, B2B o contractor.

> La primera actualización automática se está preparando.

## Antes de aplicar

Lee [¿Qué es la modalidad contractor?](CONTRACTOR.md) para conocer responsabilidades, costos y recomendaciones prácticas.

## Categorías

- Desarrollo de software
- QA y testing
- Datos e inteligencia artificial
- DevOps, cloud y ciberseguridad
- Soporte e infraestructura
- Producto, UX/UI y gestión tecnológica

## Criterios

- Solo se incluyen ofertas activas y verificadas.
- La empresa debe aceptar candidatos de LATAM o de países latinoamericanos específicos.
- La relación contractor/freelance/B2B debe estar declarada; trabajar remoto no basta.
- Se ordenan por fecha, de la más reciente a la más antigua.
- No se inventan salarios, modalidad contractual ni países elegibles.
